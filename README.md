# Crow

**Read less. Test sooner.**

Crow is a tiny AI skill for turning a real-world problem into a learning-and-action loop:

`problem → one reading → one idea → one real-world action → feedback → calibration`

It is designed for people who can think, plan, research, and read—but need reality to do more of the judging.

## What Crow does

Crow helps an AI assistant:

- identify the user's current practical problem;
- recommend one actionable reading source;
- read in small units instead of building a curriculum;
- turn one useful idea into one concrete real-world experiment;
- stop adding theory once the next action is clear;
- use actual feedback to decide whether to keep, adjust, drop, or read next.

The core rule is simple:

> **Never let reading replace testing.**

## What Crow is not

Crow is not:

- a book-summary skill;
- a habit tracker;
- a note-taking system;
- a gamified productivity app;
- a fixed coaching persona.

It preserves the user's existing relationship with their AI. If the assistant already has a name, voice, or character, Crow works through it rather than replacing it.

## Minimal loop

1. Define one practical problem.
2. Choose one primary reading.
3. Read a small amount.
4. Extract one testable idea.
5. Do one real-world action.
6. Observe what actually happened.
7. Keep, adjust, drop, or read next.

## Example

**Problem:** I keep researching the perfect way to work, but still procrastinate.

**Primary reading:** *The Now Habit* by Neil Fiore.

**Read now:** 20–25 minutes.

**Experiment:** immediately work on the avoided task for 30 minutes without researching a better method first.

**Next session:** start with what actually happened, not with another chapter.
